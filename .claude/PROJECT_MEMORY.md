# 🚀 VoiceAuto 产品核心文档

## 一、项目概述

VoiceAuto
是一个面向语音助手测试场景的一站式自动化测试平台，覆盖"用例导入 →
批量播放 → 执行控制 → 报告生成 → 日志分析"全流程。

产品目标： - 替代人工语音测试 - 提供标准化测试流程 -
提升验证效率与准确性

当前形态： - 纯前端应用（Browser-Based） - 本地执行 + 本地存储

------------------------------------------------------------------------

## 二、核心价值

-   提升测试效率（批量执行）
-   标准化测试流程
-   自动生成报告
-   快速问题定位
-   零部署使用

## 四、系统功能结构

VoiceAuto

├── 语音测试模块

│   ├── 音频配置
│   ├── 测试用例管理

    └── 统计分析

## 五、核心业务流程

### 语音测试流程

[开始]
   ↓
[配置唤醒词与语音参数]
   ↓
[导入测试用例]
   ↓
[进入执行队列]
   ↓
┌────────────────────────────┐
│        单条用例执行         │
│                            │
│  唤醒词 → 延迟 → 播放音频  │
│        → 间隔延迟          │
└────────────────────────────┘
   ↓
[记录执行结果]
   ↓
{是否还有用例 / 是否达到循环次数？}
   ↓            ↓
  是            否
   ↓            ↓
[继续执行]     [汇总结果]
   ↓            ↓
   └────────────┘
          ↓
   [生成测试报告]
          ↓
       [结束]

### 日志分析流程

[开始]
   ↓
[导入日志文件]
   ↓
[解析日志（结构化处理）]
   ↓
[设置筛选条件]
   ↓
[执行日志筛选]
   ↓
{是否命中异常日志？}
   ↓            ↓
  是            否
   ↓            ↓
[标记异常]     [正常数据]
   ↓            ↓
   └──────┬─────┘
          ↓
   [统计分析]
          ↓

## 六、核心功能说明

### 语音测试

-   唤醒词配置（延迟/间隔/试听）
-   音频配置（音色/语速/音量）
-   用例管理（文本/音频/手动）
-   播放控制（开始/暂停/停止）
-   测试报告（成功率/耗时/导出）

### 日志分析

-   日志导入
-   自动结构化解析
-   多维筛选（时间/关键字/级别）
-   统计分析输出

------------------------------------------------------------------------

## 七、数据与状态设计

-   持久化数据：配置、用例、日志
-   运行时状态：播放进度、状态机
-   报告数据：执行结果统计

技术实现： - React Context + useReducer - localStorage 持久化

------------------------------------------------------------------------

## 八、技术架构

-   React 18
-   Vite 5
-   Tailwind CSS
-   Web Speech API / 豆包TTS
-   Blob 下载报告

------------------------------------------------------------------------

## 九、核心设计约束

-   严格顺序执行（不可并发）
-   单线程播放队列
-   报告数据必须真实记录
-   TTS失败自动回退

------------------------------------------------------------------------

## 十、非功能要求

-   高可用性
-   高性能（本地执行）
-   数据安全（不上传）
-   浏览器兼容

------------------------------------------------------------------------

## 十一、已知限制

-   浏览器语音能力差异
-   自动播放策略限制
-   大日志文件限制
-   报告格式仅txt
