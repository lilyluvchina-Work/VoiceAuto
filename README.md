# VoiceAuto - 语音自动化测试平台

基于 React 的语音助手自动化测试平台，支持豆包 TTS 与 Web Speech 双通道。

## 文档定位

- 目标读者：首次接触项目的开发与测试同学。
- 内容范围：快速启动、功能总览、使用流程、技术栈与目录概览。

## 功能特性

- 🔔 **唤醒词管理**：自定义唤醒词、唤醒后延迟、唤醒间延迟
- 🎵 **音频用例管理**：支持文本导入、文件导入、手动输入生成，并支持按功能模块归类
- 🎛️ **音频配置**：多种音色、语种、方言、音量、倍速调节
- ▶️ **播放控制台**：开始/暂停/停止、进度显示、测试报告
- ✨ **播放高亮**：测试执行时，当前播放用例在列表中实时高亮
- 📊 **测试报告**：自动生成测试报告，支持复制和导出
- 🧩 **结构化报告**：测试报告支持 JSON / CSV 导出，便于外部系统对接
- 🧾 **测试过程记录**：测试报告独立为顶部 Tab，测试中持续刷新
- 🗂️ **Langfuse 日志**：支持 UAT/TEST/PROD 多环境拉取、解析与导出
- 🤖 **自动联动**：测试完成后自动回填 Langfuse 时间范围并自动获取日志
- 📦 **生产代理示例**：提供 Nginx 反向代理配置样例，便于生产部署

## 使用说明

### 1. 配置唤醒词

在「唤醒词配置」模块中：
- 设置唤醒词文本（默认：Hey, Cedar）
- 调整唤醒后延迟（唤醒词播放后等待时间）
- 调整唤醒间延迟（默认 20s）
- 点击「试听唤醒词」试听唤醒音频

### 2. 配置音频参数

在「音频配置」模块中：
- 选择音色（晓晓、晓伊、云希、云健等）
- 选择语种/方言
- 调节音量和播放倍速

### 3. 导入测试音频

三种导入方式：
- **文本导入**：上传 .txt 文件，每行一条用例
- **文件导入**：直接导入音频文件（mp3/wav/ogg/m4a）
- **手动输入**：输入文本后点击生成
- **功能模块归类**：导入前可通过下拉框选择模块分类

### 4. 执行测试

1. 确保已添加测试音频
2. 点击「开始测试」或按 Enter 键
3. 测试流程：唤醒词 → 唤醒后延迟 → 测试音频 → 唤醒间延迟（默认 20s）→ 循环
4. 使用空格键暂停/继续，Esc 键停止
5. 当前播放中的测试音频会在列表中高亮显示

### 5. 查看报告

测试完成后自动生成报告，包含：
- 测试时间、唤醒词配置
- 总用例数、成功/失败数、成功率
- 总耗时、平均每条用时
- 测试详情列表

## 技术栈

- **前端框架**：React 18
- **样式**：Tailwind CSS
- **语音合成**：豆包 TTS / Web Speech API
- **状态管理**：React Context
- **打包工具**：Vite
