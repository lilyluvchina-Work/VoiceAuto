# 音箱黑盒测试开发记录

依据：`音箱黑盒语音测试实现方案.md`。本次直接执行用户指定方案，不重新设计产品。

## 实施顺序

1. 独立声音判定核心：连续语音确认、模板匹配、回溯起点、超时和重叠计时；Python 单元测试。
2. 本机全双工工作进程：共享 ADC/DAC 时钟，原始 WAV 实时落盘，底噪、泄漏/残响和唤醒样本校准，完整唤醒重试状态机。
3. 桥接管理：分块 WAV 上传、运行/停止/恢复、原子 JSON 保存、录音读取；Node 测试。
4. 独立统计及离线 HTML 报告：明确统计分母，缺失值、分位数、转义和相对录音路径；Node 测试。
5. React 入口及操作面板：设备与配置、样本、目录导入、进度、录音回放、ZIP 导出、历史恢复。
6. 构建、回归、审查；实机验收单独记录，不将模拟测试作为实机验证。

## 接口与约束

- 新增 `/api/audio/blackbox`，沿用本机音频接口 Origin 限制。
- 上传音频统一为单声道 16-bit PCM WAV；每块不超过 256 KiB，避免现有 1 MiB 请求上限。
- 后端使用 sounddevice RawStream，输入、输出独立选择；帧长 20 ms。
- 语音使用 WebRTC VAD 并排除窄带提示音。无 VAD 依赖时拒绝开始，不能退化为音量检测。
- 无专业 AEC 时明确使用播放屏蔽与校准残响保护模式；无法测量播放期间重叠回复，报告须列出限制。保留完整原始录音以供复核。
- 每条测试首次加最多 5 次超时重试；执行错误不消耗超时重试，终止本任务避免设备异常继续污染结果。
- 不覆盖工作区已有修改，不自动提交、部署或推送。

## 使用与运维

1. 在连接外接扬声器和麦克风的 Windows 电脑运行 `powershell -ExecutionPolicy Bypass -File scripts/installNativeAudio.ps1`，安装 sounddevice 和 WebRTC VAD。已有虚拟环境也需执行，以补齐 VAD。
2. 运行 `npm run adb:bridge`。修改代码或安装依赖后需重启桥接。默认监听 `127.0.0.1:17321`。
3. 若网页来自远程 HTTP 服务，使用 `VOICEAUTO_AUDIO_ORIGINS` 配置允许的完整 Origin（包含端口，多个以逗号分隔）。沿用现有本机音频接口授权规则。
4. 在“测试用例管理”按工具原有流程导入用例并生成测试音频；黑盒模块沿用“已生成音频”、测试模块筛选和目录排序，不再单独导入测试目录。在“音箱黑盒测试”检测并分别选择输入、输出设备。唤醒词随设备切换为“小爱同学 / 小度小度 / Hey Google”，可手动编辑，试听与正式测试使用当前文字通过原有 TTS 接口生成音频。Google 音箱需先开启唤醒提示音。
5. 选择设备后会同步切换唤醒词、参考应答和回应类型。首次点击“开始测试”将自动采集实际唤醒回应，再进入测试；已有样本时直接使用。保持环境安静，完成后回放校准录音和样本。也可展开“更多设置与应答样本”重新采集或导入多个手工裁剪的实际回应（每个有效长度不超过 5 秒，最多 20 个）。
6. 根据校准录音调整“播放后残响屏蔽”及输入/输出补偿。该版本不自动推断声学延迟：ADC/DAC 时间可用性检查不能替代已知间隔实机校验。
7. 开始测试。每次尝试执行完整唤醒链路，超时额外重试 0–5 次；设备/文件错误终止任务并保留录音。持续发声时会暂停等待安静，可停止。
8. 完成或停止后复核逐次结果和录音，可标记“疑似干扰”等。导出 ZIP 后**先解压**，离线打开 `report.html`；录音使用相对路径，无外部 CDN。
9. 本机任务保存在 `logs/speaker-blackbox/<任务 UUID>/`，包含 `results.json`、`config.json`、`report.html`、`assets/` 和 `recordings/`。尝试开始与结束即时保存 JSON，WAV 每帧更新头部并刷新。刷新网页可恢复最近任务；桥接异常重启后通过“刷新历史任务”恢复，未完成尝试标记异常中断。历史任务不会继续执行或覆盖，重新测试请创建新任务。

## 已知测量边界

- 本版本使用 `playback_guard_no_aec`，未实现专业自适应回声消除。所有报告与界面明确标注降级模式。
- 电脑播放和配置的残响窗口内不判定回复，因此无法发现该窗口中的提前回复；窗口结束后首次有效语音才计时。实际残响超过保护窗口时仍可能误判，必须先校准并复核录音。
- VAD + 频谱提示音过滤和唤醒频谱序列匹配不提供说话人分离，也不验证回答语义。
- WebRTC VAD 依赖说明：[项目 PyPI 页面](https://pypi.org/project/webrtcvad-wheels/)。缺失依赖时直接报错，不以音量检测静默替代。
