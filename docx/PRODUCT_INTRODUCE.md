# VoiceAuto 产品文档

## 文档定位

- 目标读者：产品、测试、研发协作人员。
- 内容范围：产品目标、能力边界、业务流程、非功能要求与迭代方向。

## 1. 产品概述

VoiceAuto 是一个面向语音助手测试场景的前端自动化测试平台。产品提供从测试用例导入、语音参数配置、批量播放执行到报告导出与日志分析的一体化流程，帮助测试与开发团队快速完成语音交互能力验证。

当前版本由前端页面配合 Node 后端服务组成，支持登录、配置中心数据库持久化、豆包 V3 TTS 后端代理和 Web Speech 回退能力。需要自动判断 Speaker 唤醒、ASR 和 Speaker 播报音频收录状态时，可配套启用本地 ADB Bridge 读取设备日志。

## 2. 目标用户

- 语音助手测试工程师
- 语音产品研发工程师
- 需要批量验证语音文案播放效果的产品经理

## 3. 核心价值

- 提升测试效率：批量执行语音用例，减少重复人工点击。
- 提升可追溯性：自动生成结构化测试报告，支持 Markdown、HTML、Excel 导出。
- 提升问题定位速度：提供日志导入与多维筛选分析能力。
- 提升自动判定能力：通过 ADB 日志、Speaker 响应录音和过程记录自动判断唤醒、ASR、Speaker 播报音频收录链路状态。
- 降低使用门槛：常规功能以前端页面为主，Speaker 自主监测按需启用本地 ADB Bridge。

## 4. 功能范围

### 4.1 语音测试模式

#### 4.1.1 唤醒词配置

- 配置唤醒词文本。
- 配置唤醒后延迟（wakeAfterDelay）。
- 配置唤醒间延迟（wakeIntervalDelay）。
- 支持“试听唤醒词”即时验证。
- 之前：唤醒词配置作为独立卡片展示。
- 现在：唤醒词配置已合并到播放控制台，和测试过程、开始/停止/重置操作位于同一主区域。

#### 4.1.2 音频配置

- 音色选择（当前展示 `seed-tts-2.0` Resource ID 下验证通过的可用音色）。
- 语种/方言选择。
- 音量调节（0%~200%）。
- 播放倍速调节（0.5x~2.0x）。

#### 4.1.3 测试用例导入

- 文本导入：上传 txt，每行一条用例。
- 文件导入：支持 mp3/wav/ogg/m4a，多文件导入。
- 手动输入：可粘贴多行文本生成多条用例。
- 模块归类：导入时可指定模块（含自定义模块）。

#### 4.1.4 播放控制台

- 开始、暂停、继续、停止、重置。
- 支持循环播放次数配置（当前支持 1/2/3/5/10/20/50 次）。
- 顶部“测试过程”面板集中显示当前状态、当前阶段、当前文本、进度、完成率、已用时间和预计剩余时间。
- 开始、暂停/继续、停止、重置按钮位于“测试过程”面板下方。
- 支持播放序列调试日志开关，可在控制台输出真实执行序列。
- 支持按测试模块执行，并可选择测试结束后自动拉取的 Langfuse 日志环境。
- 自动拉取开启时，测试完成后会停留语音测试页 2 分钟，再跳转 Langfuse 日志页拉取所选环境日志。
- 支持 Speaker 监听链路自检：检查 ADB、Speaker 在线状态、logcat 可读状态，并支持一键恢复监听链路。
- 支持自主监测配置：
  - 自主监测唤醒是否成功：通过 ADB 日志识别 `WakeupSuccess`，连续失败后可触发 ADB 重启恢复。
  - 自主监测测试音频与 ASR 输入：通过 ADB 日志识别 ASR 生命周期，并从 `asr_status/input_text` 日志提取实际 ASR 文本。
  - 自主监测 Speaker 响应内容：通过麦克风录制 Speaker 播报音频，并展示 Speaker 播报音频收录文本。
- 支持响应录音参数配置：麦克风、响应窗口、最大录制时长、静音结束阈值、最短保护时长、噪声阈值、前后置缓存、下一轮唤醒冷却等。
- 键盘快捷键：
  - Enter：开始
  - Space：暂停/继续
  - Esc：停止

#### 4.1.5 测试过程记录与报告

- 统计总用例、成功数、失败数、成功率。
- 统计唤醒、ASR、Speaker 播报音频收录各阶段成功/失败次数。
- 统计总耗时与平均每条耗时。
- 展示用例执行明细。
- 测试过程记录页支持点击展开每条用例详情，展示唤醒、测试音频、ASR、Speaker 播报音频收录链路过程。
- 每条记录展示整体结果，以及唤醒状态、测试音频状态、ASR 状态、Speaker 播报音频收录状态。
- 详情中展示 Speaker 播报录音播放器、下载入口、Speaker 播报音频收录文本、文本相似度、录音时长、采样率、结束原因和疑似截断标记。
- 支持 JSON、CSV、文本报告导出；测试过程记录支持 Excel 导出。
- 过程记录 Excel 包含“概览”和“具体数据”两个 Sheet，具体数据中相同用例级字段会合并单元格。
- 报告中保留 Speaker 播报录音文件名、响应录音 ASR、文本相似度和录音诊断字段。
- 测试进行中可点击“查看报告”，且不会打断当前音频播放。
- 报告数据为空时提供明确占位提示，避免空白视图。

### 4.2 日志分析模式

- 支持任意后缀日志文件按文本导入。
- 自动解析时间、级别、模块、消息。
- 支持按文件名、导入日期筛选日志记录。
- 支持按时间区间、关键字、日志级别筛选日志条目。
- 输出统计与分析结论，辅助问题定位。
- 本地缓存日志记录（localStorage），并在容量不足时自动降级压缩保存。

### 4.3 Langfuse 日志获取模式

- 支持从 Langfuse 平台拉取 **Traces** 与 **Observations** 数据。
- 支持多环境切换，切换后自动使用对应凭据：
  - **UAT**（紫色标识）
  - **UAT-Local**（青色标识）
  - **TEST**（黄色标识）
  - **PROD**（红色标识）
- 时间范围选择器支持精确到秒的开始/结束时间配置，并提供快捷选择（15 分钟 / 1 小时 / 6 小时 / 24 小时 / 3 天 / 7 天）。
- 自动分页拉取所有数据（每页 100 条），显示实时进度。
- 支持 **暂停 / 继续 / 终止并保留** 当前已获取数据。
- 自动过滤 input、output、name 均为空的无效记录，并统计过滤数量。
- 自动关联 Traces 与 Observations 的 Session，展示匹配的 SessionID 列表。
- 支持数据预览（表格展示，悬浮查看完整字段内容，横向滑动）。
- 日志提取预览支持按 familyid / deviceid 筛选；启用筛选后，生成报告与日志提取 Excel 基于筛选结果。
- 支持导出 Excel（Traces + Observations 各一个 Sheet）与 JSON 格式下载。
- 支持基于日志提取结果生成总结报告。

### 4.4 总结报告模式

- 集中展示最新一次由 Langfuse 日志生成的总结报告。
- 基础信息与功能模块统计为只读展示，避免误改自动统计口径。
- 提测参数支持按“模型配置 / 语音识别配置”分组编辑，并可导入 `.xlsx/.xls/.csv/.txt` 参数文件。
- 报告表格以本次实际执行音频为主，未执行用例不计入本次报告。
- 报告正文采用 Markdown 表格结构，可导出 Markdown、HTML、Excel。
- Excel 报告包含汇报看板、报告概览、提测参数、功能模块统计、错误信息、重点数据和测试明细。

## 5. 关键业务流程

### 5.1 语音测试流程

1. 用户配置唤醒词与语音参数。
2. 用户导入或手动添加测试用例。
3. 用户按需开启自主监测：唤醒检测、ASR 输入检测、Speaker 响应检测。
4. 用户启动测试。
5. 固定等待模式下，系统按“唤醒词 -> 唤醒后延迟 -> 测试音频 -> 唤醒间延迟”执行。
6. 自主监测模式下，系统按事件驱动执行：检测到唤醒成功后播放测试音频，测试音频结束后立即监听 Speaker 响应，播报结束并冷却后进入下一条唤醒。
7. 系统实时记录每条用例的唤醒、ASR、Speaker 播报音频收录状态和过程详情。
8. 测试停止或完成后生成过程报告；若开启自动拉取，则停留 2 分钟后跳转 Langfuse 并拉取所选环境日志。

### 5.2 日志分析流程

1. 用户导入日志文件。
2. 系统解析并生成结构化日志条目。
3. 用户按条件筛选日志。
4. 系统输出统计结果与重点异常信息。

### 5.3 Langfuse 日志获取流程

1. 用户选择目标环境（UAT / UAT-Local / TEST / PROD）。
2. 用户选择时间范围（精确到秒）。
3. 用户点击"获取日志"，系统分页并发拉取 Traces 和 Observations。
4. 用户可随时暂停、继续或终止（终止后保留已获取数据）。
5. 获取完成后系统自动过滤空记录，关联 Session，展示统计卡片。
6. 用户可按 familyid / deviceid 筛选日志提取结果。
7. 用户预览数据、下载 Excel / JSON，或生成总结报告。

## 6. 数据与状态（前端）

- 全局状态通过 React Context + useReducer 管理。
- 持久化内容：唤醒词配置、默认语音配置、测试选项（循环次数/调试开关/自动拉取环境/模块筛选）、测试用例列表、日志记录（部分压缩）。
- 临时运行状态：播放状态、总队列进度、当前列表索引、报告中间数据。

## 7. 技术方案

- 前端框架：React 18
- 构建工具：Vite 5
- 样式：Tailwind CSS
- ADB Bridge：Node.js 本地桥接服务，用于读取 `adb devices`、`adb logcat`、执行 ADB 自检和恢复。
- 语音合成：
  - Web Speech API（默认）
  - 豆包 V3 TTS（可选，配置中心维护，后端代理调用）
- Speaker 响应录音：Web Audio API 连续 PCM 采样并编码 WAV。
- 报告导出：浏览器 Blob 下载 txt / Markdown / HTML，xlsx 导出 Excel
- 过程记录导出：xlsx 导出“概览 / 具体数据”双 Sheet，并支持明细合并单元格。
- Langfuse 日志导出：xlsx 库导出 Excel，Blob 下载 JSON
- 错误日志汇总：`npm run logs:errors` 汇总多日志文件到 `logs/error-summary.log`
- Langfuse 接入：Vite Dev Proxy 转发（绕过 CORS），Basic Auth 鉴权

## 8. 环境配置

可选启用豆包 V3 TTS，推荐在配置中心维护：

- APP ID
- Access Token
- Secret Key
- Resource ID

浏览器通过后端 `/api/tts/doubao-v3` 代理请求豆包，密钥不直接暴露给前端。当前音色列表只展示 `seed-tts-2.0` 下已验证可播放的音色。

## 9. 非功能要求

- 可用性：界面操作反馈明确，关键操作具备错误提示。
- 兼容性：优先支持现代浏览器（Chrome/Edge/Firefox/Safari 新版本）。
- 性能：常规测试与日志分析在前端本地处理，避免网络依赖。
- 安全性：不上传用户日志与测试文本到平台后端（除用户主动配置外部 TTS 服务请求）。

## 10. 已知限制

- Web Speech 语音质量与可用音色受浏览器与系统环境影响。
- 浏览器自动播放策略可能影响首次播放体验。
- 大体积日志文件受浏览器内存和 localStorage 容量限制。
- 当前暂未提供 PDF 报告导出。
- 当循环次数较高（例如 50 次）且用例较多时，整体执行时间会明显增加。
- Langfuse 代理仅在 Vite 开发服务器（`npm run dev`）下生效；生产构建需额外配置反向代理。
- Langfuse 大时间跨度查询（如 7 天）可能需要较长拉取时间，受网络和数据量影响。
- 自主监测依赖本地 ADB、Speaker 设备在线、logcat 可读和浏览器麦克风权限。
- Speaker TTS 录音稳定性受麦克风输入源、Speaker 音量、环境噪声和系统音频通道影响。

## 11. 迭代建议

- 增加测试任务模板与批量参数预设。
- 增加测试结果对比（历史版本成功率变化趋势）。
- 增加报告格式扩展（JSON/CSV/PDF）。
- 增加日志异常规则引擎（可配置告警规则）。
- 增加多环境配置管理（开发/测试/生产）。

## 12. 验收标准

- 可完成唤醒词配置、语音参数配置与测试用例导入。
- 可稳定执行完整语音测试流程并展示进度。
- 可生成并导出测试报告。
- 开启自主监测时，可展示唤醒、ASR、Speaker 播报音频收录三阶段状态，并保留播报音频收录文本和录音。
- 可导入日志并执行筛选分析。
- 刷新页面后关键配置与用例可恢复。
