# VoiceAuto 产品文档

## 文档定位

- 目标读者：产品、测试、研发协作人员。
- 内容范围：产品目标、能力边界、业务流程、非功能要求与迭代方向。

## 1. 产品概述

VoiceAuto 是一个面向语音助手测试场景的前端自动化测试平台。产品提供从测试用例导入、语音参数配置、批量播放执行到报告导出与日志分析的一体化流程，帮助测试与开发团队快速完成语音交互能力验证。

当前版本主要运行在浏览器端，支持 Web Speech API，并可通过环境变量切换为豆包 TTS 优先、Web Speech 回退的双通道语音合成策略。

## 2. 目标用户

- 语音助手测试工程师
- 语音产品研发工程师
- 需要批量验证语音文案播放效果的产品经理

## 3. 核心价值

- 提升测试效率：批量执行语音用例，减少重复人工点击。
- 提升可追溯性：自动生成结构化测试报告，支持复制和下载。
- 提升问题定位速度：提供日志导入与多维筛选分析能力。
- 降低使用门槛：纯前端部署，开箱可用，无需额外后端服务。

## 4. 功能范围

### 4.1 语音测试模式

#### 4.1.1 唤醒词配置

- 配置唤醒词文本。
- 配置唤醒后延迟（wakeAfterDelay）。
- 配置唤醒间延迟（wakeIntervalDelay）。
- 支持“试听唤醒词”即时验证。

#### 4.1.2 音频配置

- 音色选择（男女声）。
- 语种/方言选择。
- 音量调节（0%~200%）。
- 播放倍速调节（0.5x~2.0x）。

#### 4.1.3 测试用例导入

- 文本导入：上传 txt，每行一条用例。
- 文件导入：支持 mp3/wav/ogg/m4a，多文件导入。
- 手动输入：可粘贴多行文本生成多条用例。
- 模块归类：导入时可指定模块（含自定义模块）。

#### 4.1.4 播放控制台

- 开始、暂停、继续、停止、重置。
- 支持循环播放次数配置（当前支持 1/2/3/5/10/20/50 次）。
- 显示当前状态、当前进度、已用时间、预计剩余时间。
- 展示当前播放内容与播放阶段（唤醒词/测试音频/延迟）。
- 支持播放序列调试日志开关，可在控制台输出真实执行序列。
- 键盘快捷键：
  - Enter：开始
  - Space：暂停/继续
  - Esc：停止

#### 4.1.5 测试报告

- 统计总用例、成功数、失败数、成功率。
- 统计总耗时与平均每条耗时。
- 展示用例执行明细。
- 支持“复制报告”与“下载 txt 报告”。
- 测试进行中可点击“查看报告”，且不会打断当前音频播放。
- 报告数据为空时提供明确占位提示，避免空白视图。

### 4.2 日志分析模式

- 支持任意后缀日志文件按文本导入。
- 自动解析时间、级别、模块、消息。
- 支持按文件名、导入日期筛选日志记录。
- 支持按时间区间、关键字、日志级别筛选日志条目。
- 输出统计与分析结论，辅助问题定位。
- 本地缓存日志记录（localStorage），并在容量不足时自动降级压缩保存。

### 4.3 Langfuse 日志获取模式

- 支持从 Langfuse 平台拉取 **Traces** 与 **Observations** 数据。
- 支持三套环境切换，切换后自动使用对应凭据：
  - **UAT**（紫色标识）
  - **TEST**（黄色标识）
  - **PROD**（红色标识）
- 时间范围选择器支持精确到秒的开始/结束时间配置，并提供快捷选择（15 分钟 / 1 小时 / 6 小时 / 24 小时 / 3 天 / 7 天）。
- 自动分页拉取所有数据（每页 100 条），显示实时进度。
- 支持 **暂停 / 继续 / 终止并保留** 当前已获取数据。
- 自动过滤 input、output、name 均为空的无效记录，并统计过滤数量。
- 自动关联 Traces 与 Observations 的 Session，展示匹配的 SessionID 列表。
- 支持数据预览（表格展示，悬浮查看完整字段内容，横向滑动）。
- 支持导出 Excel（Traces + Observations 各一个 Sheet）与 JSON 格式下载。

## 5. 关键业务流程

### 5.1 语音测试流程

1. 用户配置唤醒词与语音参数。
2. 用户导入或手动添加测试用例。
3. 用户启动测试。
4. 系统按“唤醒词 -> 唤醒后延迟 -> 测试音频 -> 唤醒间延迟”执行单条流程，并按配置循环次数重复直到全部完成。
5. 系统实时记录每条用例执行结果。
6. 测试停止或完成后生成报告。

### 5.2 日志分析流程

1. 用户导入日志文件。
2. 系统解析并生成结构化日志条目。
3. 用户按条件筛选日志。
4. 系统输出统计结果与重点异常信息。

### 5.3 Langfuse 日志获取流程

1. 用户在标题栏选择目标环境（UAT / TEST / PROD）。
2. 用户选择时间范围（精确到秒）。
3. 用户点击"获取日志"，系统分页并发拉取 Traces 和 Observations。
4. 用户可随时暂停、继续或终止（终止后保留已获取数据）。
5. 获取完成后系统自动过滤空记录，关联 Session，展示统计卡片。
6. 用户预览数据或下载 Excel / JSON。

## 6. 数据与状态（前端）

- 全局状态通过 React Context + useReducer 管理。
- 持久化内容：唤醒词配置、默认语音配置、测试选项（循环次数/调试开关）、测试用例列表、日志记录（部分压缩）。
- 临时运行状态：播放状态、总队列进度、当前列表索引、报告中间数据。

## 7. 技术方案

- 前端框架：React 18
- 构建工具：Vite 5
- 样式：Tailwind CSS
- 语音合成：
  - Web Speech API（默认）
  - 豆包 TTS（可选，需环境变量）
- 报告导出：浏览器 Blob 下载 txt
- Langfuse 日志导出：xlsx 库导出 Excel，Blob 下载 JSON
- Langfuse 接入：Vite Dev Proxy 转发（绕过 CORS），Basic Auth 鉴权

## 8. 环境配置

可选启用豆包 TTS，主要变量如下：

- VITE_TTS_PROVIDER
- VITE_DOUBAO_TTS_URL
- VITE_DOUBAO_APP_ID
- VITE_DOUBAO_ACCESS_TOKEN
- VITE_DOUBAO_CLUSTER
- VITE_DOUBAO_VOICE_TYPE
- VITE_DOUBAO_UID

当 provider 为 doubao 且配置可用时优先豆包；失败自动回退 Web Speech。

## 9. 非功能要求

- 可用性：界面操作反馈明确，关键操作具备错误提示。
- 兼容性：优先支持现代浏览器（Chrome/Edge/Firefox/Safari 新版本）。
- 性能：常规测试与日志分析在前端本地处理，避免网络依赖。
- 安全性：不上传用户日志与测试文本到平台后端（除用户主动配置外部 TTS 服务请求）。

## 10. 已知限制

- Web Speech 语音质量与可用音色受浏览器与系统环境影响。
- 浏览器自动播放策略可能影响首次播放体验。
- 大体积日志文件受浏览器内存和 localStorage 容量限制。
- 当前报告格式以 txt 为主，暂无结构化报表导出（如 xlsx/pdf）。
- 当循环次数较高（例如 50 次）且用例较多时，整体执行时间会明显增加。
- Langfuse 代理仅在 Vite 开发服务器（`npm run dev`）下生效；生产构建需额外配置反向代理。
- Langfuse 大时间跨度查询（如 7 天）可能需要较长拉取时间，受网络和数据量影响。

- 可完成唤醒词配置、语音参数配置与测试用例导入。

- 可生成并导出测试报告。
- 可导入日志并执行筛选分析。
- 刷新页面后关键配置与用例可恢复。
