# 项目周报（2026-05-25 ~ 2026-05-29）

## 1. 本周结论

- 本周核心工作聚焦在“总结报告能力升级 + Langfuse 日志提取稳定性与可用性提升”。
- 报告链路已形成从日志提取、筛选、结构化对齐到多格式导出的闭环，数据准确性与可读性明显提升。
- 线上高频问题（Langfuse 拉取偶发 ECONNRESET 中断）已完成修复，拉取稳定性增强。

## 2. 本周项目更新

### 2.1 总结报告能力升级（2026-05-27）

- 恢复总结报告菜单入口，Langfuse 页面统一使用“生成报告”入口。
- 报告内容改为本地保存与页面展示，取消邮件发送流程。
- 基础信息补充：导入测试计划、用例总数、执行数量、执行率、测试时间、测试负责人。
- 提测参数补充：tenant/user/family 等字段，缺失统一展示为 `/`。
- 页面结构优化为分区展示（基础信息、提测参数、模块统计、报告正文），提升可读性与可维护性。

### 2.2 报告口径与匹配策略优化（2026-05-27）

- 报告表格以“测试计划目标文本”为主，确保目标文本完整展示。
- Agent 命中率、平均耗时支持按模块统计，并输出整体汇总指标。
- 日志与用例对齐优先级升级：`run_id + case_id` > `case_id` > `audio_file` > 时间窗口/相似度/顺序兜底。
- 增加日志唯一占用规则：一条日志仅匹配一条目标文本，降低多对一错配风险。
- 通过判定口径统一为“目标 Agent 与命中 Agent 一致”。

### 2.3 Langfuse 提取与页面交互增强（2026-05-29）

- 新增 familyid/deviceid 双维度筛选能力，支持一键重置。
- 启用筛选后，“生成报告”“下载日志提取 Excel”基于筛选结果执行。
- 总结报告页面“基础信息”“功能统计”调整为只读，减少人工误改风险，提升报告一致性。
- 播放控制台新增日志环境选择，并新增 UAT-Local 环境。
- 自动拉取链路调整为测试完成后停留 2 分钟再跳转 Langfuse，降低末尾日志未落库导致的漏数风险。
- 总结报告支持参数文件导入，并新增 Markdown、HTML、Excel 导出。
- 日志提取升级为按有效 Trace/Request 生成行，补充命中子 Agent、Agent 来源/置信度、日志状态与错误合并能力。
- 报告统计口径调整为只统计本次实际执行音频，未执行的导入用例不计入本次报告。

## 3. 本周 Bug 修复

### 3.1 报告准确性相关修复（2026-05-27）

- 修复报告未显示全部目标文本问题。
- 修复目标文本与实际输入无法稳定一一对应问题。
- 修复实际输入/输出/命中 Agent 提取为空或提取错误问题。
- 修复目标 Agent 无法稳定从 TAPD 自定义字段读取问题。
- 修复测试音频调整顺序或删除后执行顺序未及时生效问题。

### 3.2 Langfuse 拉取稳定性修复（2026-05-29）

- 修复 `read ECONNRESET` 导致整轮拉取中断问题。
- 分页拉取新增网络瞬时故障重试（指数退避），降低单次链路抖动影响。
- Vite 代理增加 `timeout/proxyTimeout`，提升代理链路稳定性。
- 修复自动拉取日志窗口过短导致末尾日志缺失问题。
- 修复删除 TAPD 测试音频时误移除导入用例问题。
- 修复 `[error]` observation 与有效输入分离导致报告错误信息缺失问题。

## 5. 风险与下周建议

- 风险：当前核心 JS chunk 体积仍偏大（build 有 >500k 警告），后续可通过拆包优化首屏加载。
- 建议 1：补充关键链路自动化回归（报告匹配、日志筛选、音频顺序执行）。
- 建议 2：为 Langfuse 网络重试增加可视化状态提示（第几次重试、当前阶段）。
- 建议 3：继续收敛报告字段口径，避免前后端或多来源字段命名漂移。
